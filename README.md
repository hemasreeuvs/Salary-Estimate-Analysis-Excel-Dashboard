# Salary-Estimate-Analysis-Excel-Dashboard

# Summary of the Project

This project involved analyzing salary estimates for Data Science roles, specifically Data Scientists and Data Analysts, across different U.S. states, company sizes, and job roles. 

 # The key aspects of the analysis included:

1. **Data Cleaning with Power Query** – Raw salary data was cleaned, transformed, and structured using Power Query, ensuring consistency and accuracy for analysis.

2. **State-wise Salary Estimates** – A comparison of salary variations across different states to identify regional trends.
   
3. **Company Size Impact** – Analysis of how salaries differ based on company size, categorized into small, medium, and large enterprises.
   
4.  **Role-Based Salary Trends**  – A breakdown of salary estimates for Data Scientists and Data Analysts to highlight industry benchmarks.
   
Advanced Excel techniques such as pivot tables, data visualization (charts, heatmaps), and filtering were used to present insights effectively. This analysis helps job seekers and businesses understand salary trends and make data-driven decisions.
